Root Toolbox

Nettoyage des caches, gestion des applications et diagnostics Android.

Des outils pour votre appareil

Root Toolbox rassemble le nettoyage rapide ou sélectif des caches, la gestion des applications, la vérification du root et des outils de diagnostic, notamment pour ADB.

Les opérations peuvent être consultées dans le journal et les rapports techniques peuvent être exportés pour vous aider à comprendre un problème.

Certaines fonctions nécessitent une autorisation superutilisateur. Le module Batterie est en bêta : les informations disponibles et leur précision varient selon l’appareil.

Besoin d’aide ?

Vous pouvez signaler un problème directement depuis l’application :

Paramètres > Support > Signaler un bug

Root ToolBox prépare automatiquement un e-mail à destination du support avec les informations utiles sur votre appareil et votre version de l’application.

Vous pouvez également choisir de joindre un rapport technique complet (.txt) afin de faciliter le diagnostic. Cette pièce jointe est facultative et n’est jamais envoyée automatiquement : vous gardez le contrôle final avant l’envoi depuis votre application de messagerie.

Vous pouvez aussi contacter directement le support à l’adresse roottoolboxapp@gmail.com.

Si vous contactez le support manuellement, pensez à indiquer le modèle de l’appareil, la version Android, la version de Root ToolBox et les étapes permettant de reproduire le problème.

Un contact par e-mail communique votre adresse e-mail au support.
