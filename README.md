# Root Toolbox — Support

Site de présentation et support du projet Android Root Toolbox.

- `index.html` : page d’accueil et lien vers le support.
- `privacy.html` : **brouillon**, à valider sur le code et l’APK final avant utilisation sur Google Play.

Le code source Android n’est pas contenu dans ce dépôt.

## Publication

Dans les réglages du dépôt : **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Adresse prévue après activation : https://roottoolboxapp.github.io/root-toolbox-support/

## Support

Utilisez les tickets de ce dépôt. Ils sont publics : retirez les données personnelles avant de joindre un rapport ou une capture.
